Changes for graphicsdemoskeleton, 2026:
- GLSL translated to HLSL shader model 5.0, executed as a DirectX 11 compute
  shader compiled at startup from embedded HLSL, with a custom Win32 entry point.
- Source compaction changes formatting and identifiers only; the build
  verifies identical stripped FXC bytecode before embedding the source.
- The GLSL matrix's column ordering is made explicit in HLSL. The descending
  tree-line smoothstep is expressed as one minus an ascending smoothstep.
- Repeated terrain/normal evaluations use rolled loops to limit bytecode.
- Each noise function shares one hash evaluator across its four corners.
  Ray marching and binary refinement share one terrain evaluator while
  retaining the original sample order and iteration limits.
- Terrain height queries share one noise evaluator across amplitude,
  coarse octaves, broad relief, tree-line noise, trees, and finer octaves.
  Query modes retain the original operation order and tree-state updates.
- Fractional hashes use precise arithmetic; final colors are clamped to the
  display range, and out-of-image compute threads return immediately.
- The external pebble texture used only for a water-glint mask is replaced
  by procedural noise. No image or audio assets from Shadertoy are included.
- The default monoscopic view, horizontal camera path, and mouse-X time
  shift are retained. The terrain-following altitude is replaced by a fixed
  cruise altitude for the selected route and a shallow fixed downward pitch.
  Travel is 25% faster, with a lower cruise floor and terrain-clearance margin.
  The flight starts earlier along the path to retain the previous endpoint.
  The route is surveyed once per compute thread group. The native application
  runs for 30 seconds and exits on Escape or window close.
